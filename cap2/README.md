## About This Repository

This repository documents my hands-on progress through the **Python Foundations Nano Course at FIAP**.

The current learning phase focuses on the essential building blocks of programming with Python: storing data, receiving user input, making decisions and repeating operations. The exercises were originally studied through FIAP materials and implemented in English to strengthen both programming foundations and technical English.

> This is a learning repository. The code reflects my current stage of development and will evolve as I progress through the course.

## Current Learning Phase

### Variables and Data Types

In this phase, I practiced:

- Creating variables with meaningful names
- Following Python's `snake_case` naming convention
- Receiving user input with `input()`
- Working with `str`, `int` and `float`
- Converting values between data types
- Checking data types with `type()`
- Displaying formatted information with `print()`

### Conditional Statements

I used conditional logic to control the flow of small programs:

- `if` for a single condition
- `if` and `else` for two possible outcomes
- `elif` for multiple decision paths
- `and` and `or` for combined conditions
- `==` for comparison
- `.upper()` to normalize text input before comparison

### Repetition Structures

I also practiced two fundamental loop structures:

- `while` to repeat instructions while a condition remains true
- `for` with `range()` to repeat instructions over a defined sequence
- Updating counters to prevent unintended infinite loops
- Generating a multiplication table with a `for` loop

## Exercises Developed

The practical activities completed during this phase include:

- Employee and company data input
- Data type verification
- Priority-care decision based on age
- Multiple decision paths using age and an infectious-disease input
- Number sequence generation using `while`
- Multiplication table generation using `for` and `range()`
